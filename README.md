# 🚚 Supply Chain Analysis Dashboard

## Overview  
The dashboard provides a comprehensive view of supply chain operations, transforming raw logistics and financial data into clear, actionable insights. It highlights key metrics such as total orders, gross revenue, COGS, profit margin, and reliability indicators, while also showcasing product category performance, customer segments, and geographic distribution. With its clean design and multi‑page storytelling, the dashboard enables executives to monitor efficiency, identify risks, and optimize supply chain strategies across regions and warehouses.

## 🚀 Strategic Value  
This project demonstrates how supply chain data can be leveraged to:  
1. **Monitor operational efficiency** — track orders, shipments, and warehouse performance.  
2. **Identify risks** — analyze reliability, delays, and risk tiers impacting revenue.  
3. **Optimize profitability** — connect product categories, customer segments, and regions to financial outcomes.  
4. **Enable executive decision‑making** — provide a high‑level summary with drill‑down capability for deeper analysis.
